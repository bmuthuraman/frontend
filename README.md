# Reen Bank — React + Bootstrap

Responsive recreation of the supplied Reen Bank landing-page PNG.

## Stack

- React
- Bootstrap 5
- Redux Toolkit
- Redux Saga
- React Router
- Lucide React

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The visual structure, color palette, section order, and responsive behavior are implemented with Bootstrap grid/utilities plus custom CSS. Redux/Saga scaffolding remains available for API-driven modules.
